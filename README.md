# PostPilot

Protótipo de estúdio de conteúdo para criadores. A partir de tema e transcrição, monta localmente ganchos, ideias de trechos e legenda; permite copiar o pacote e reabrir os últimos rascunhos.

Não processa arquivos de vídeo nem usa IA real neste protótipo. Transcrição automática, geração por IA, contas, créditos e pagamentos precisam de integração.
