# PostPilot

Protótipo de estúdio de conteúdo para criadores. A partir de tema e transcrição, monta localmente um pacote demonstrativo de ideias de cortes e textos para redes sociais.

Não processa arquivos de vídeo nem usa IA real neste protótipo. Transcrição automática, geração por IA, contas, créditos e pagamentos precisam de integração.
